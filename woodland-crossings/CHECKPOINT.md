# Woodland Crossings — checkpoint 01

Status: design checkpoint; playable implementation pending.

A separate self-guided comma-splice game. The original root game stays unchanged.

Agreed design: rabbit crossing repairs, village restoration rewards, no death/lost progress, targeted hints, natural sentence rhythms, silent stand-alone reading rather than breathing rules. Accept valid alternative repairs. Include correct commas from the start.

Progression: short clauses → dependent openings → longer clauses → however/therefore → several clauses and valid commas → unmarked paragraph editing.

Spaced practice: fresh examples after intervening tasks and local return reviews after 1, 3 and 7 days. Practical schedule, not a guaranteed optimal prescription. Assisted success advances the story; independent checks and later reviews track learning separately.

Build plan: static HTML/CSS/JS; authored bank; local save/resume; adaptive review; keyboard/mobile support; optional challenges; meaningful automated checks; gamification subagent critique before final commit.
